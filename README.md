### Utilitário de Dados Inconsistentes 

Um utilitário desenvolvido para resolver o problema de inconsistência, erros de digitação e formatação inadequada no cadastro de dados corporativos.

| Métrica | Detalhes |
|:---|:---|
| **Stack** | Python  |
| **Escala** | Utilitário CLI desenvolvido para múltiplos cadastros e processamento contínuo |
| **Performance** |  Processamento local, validações leves e manipulação eficiente de strings |
| **Segurança** |Validação de dados antes do processamento |
| **Impacto** | Redução de inconsistências, erros de digitação e problemas de formatação em dados corporativos |
| **Recursos** | Validação de CPF, e-mail e valores monetários • Padronização de nomes • Limpeza de strings |
| **Arquitetura** | Funções modularizadas com Type Hints e fluxo interativo utilizando `while True` |
| **Repositório** | [GitHub](https://github.com/duduutech/python-data-cleaner) |
